# Master
Erweiterte AutoLISP-Routinen für AutoCAD/BricsCAD

## Installation

1. Repository klonen
2. master.lsp in AutoCAD laden
3. Befehle verwenden

## Befehle

- AB+ - Abstand messen (2D)
- AG - Ausgleichen
- AM - AutoCAD-Magazin Aufteilen
- ATK - Aufteilen Kopieren ATK-, ATK+
- ATT2T - Attribut zu Text konvertieren ATT2T+
- ATTAUS - Schaltet die Anzeige einzelner Attribute aus
- ATTAN - Schaltet die Anzeige einzelner Attribute ein
- ATTBE - Mehrere Attributwerte bearbeiten (Text ersetzen der hinzufügen)
- ATTCAP - Ändert die Schreibweise von Attributen (Groß-/Kleinschreibung)
- ATTSP - Speicher Attributwerte in eine externe Datei
- ATTLAD - Ladet Attributswerte von einer externen Datei in einen Block
- ATTÜ - Attribut-/Texteigenschaften und übertragen
- ATTÜBERT - Attributswert innerhalb eines Blocks in ein anderes Attribut übertragen
- ATTVER - Attribute verschieben ATTVER+
- B2ATTZ - Block zu Attribute Z-Höhe verschieben
- B2L - Bögen zu Linien konvertieren
- B3 - Böschungsschraffur 3D
- BEFEHL - Hilfe anzeigen
- BLAUS - Blöcke ausschalten
- BLDEL - Blockdefinition löschen
- BLISO - Blöcke isolieren
- BLTAUSCH - Block tauschen BLTA
- BLTOUCH - Repariert dynamische Blöcke
- BOESCH - Böschungsschraffur 2D
- BOGL - Bogen für Gewölbedarstellung erstellen
- BR - Bruchbefehl BR+
- DU+ - Benennt mehrere Blockdefinitionen/Layer/Layout um
- FL - Fläche von geschlossen Polylinien beschriften
- GL - Gesamtlänge
- HK - Höhenkoten im Schnitt setzen
- HKG - Höhenkoten im Grundriss setzen
- KL+ - Konstruktionslinien KLH, KLV
- KOOR - Koordinatenbeschriftung markieren
- MS - Multi-
- MST - Öffnet den Maßstablisten-Manager MST+
- NISCHE - Erstellt anhand einer bestehenden Wandlinie eine Nische
- NUM - Nummeriert Texte und Attribute
- PF - Polylinie fortsetzen
- PK - Schaltet alle Layer die mit "_Punkte" beginnen
- PLAETTEN - Zeichnungen plätten
- PLOT+ - Öffnet den Internet-Explorer mit der Drucker-IP
- PPE - Fügt Stützpunkte in einer bestehenden 2D-Polylinie ein
- PPL - Löscht Stützpunkte in einer bestehenden 2D-Polylinie
- PPV - Verschiebt Stützpunkte in einer bestehenden 2D-Polylinie
- PV - Polylinien verbinden
- QSCHNITT - Querschnitt erstellen
- RBFL - Raumflächen abgleichen RBFL+
- RBNR - Raumbuchnummer generieren
- RID - Raum-Identifikationsnummern generieren
- RTNR - Raum-Türschildnummer generieren RTNR+
- SCHRAFFUM - Erzeugt Umgrenzungen von Schraffuren
- SCHNITT - Schnitt erstellen SCHNITT+
- SL - Stutzen-Linie
- ST - Stufen zeichnen ST+
- Ü - Befehlsübersetzer
- VB+ - Verbinden
- VC - Verschneiden VC+, VC#
- WAND - Wandkontur erstellen
- X - Öffnet den Explorer X+
- XNEU - XRef laden/wiederherstellen
- XENT - XRef entfernen
- XLÖS - XRef lösen
- XFARB - XRef einfärben XFARB+
- Z+ - Löscht das zu letzte erstellte Objekt
